# AI CCTV Anomaly Detection System

## Overview
This project focuses on detecting unusual activities in CCTV footage using computer vision techniques. The system analyzes video frames in real-time and identifies anomalies based on predefined conditions.

## Objective
To develop a smart surveillance system that can automatically detect suspicious or abnormal activities without manual monitoring.

## Key Features
- Real-time video processing
- Detection of unusual movements or activities
- Alert mechanism for anomalies
- Frame-by-frame analysis using computer vision

## Tech Stack
- Python
- OpenCV
- NumPy

## Approach
- Captured video input from CCTV/recorded footage
- Processed frames using OpenCV
- Applied basic anomaly detection logic (motion detection / thresholding)
- Highlighted unusual activities in frames

## Functionality
- Continuously monitors video stream
- Detects motion or irregular patterns
- Flags frames with anomalies
- Can be extended to trigger alerts

## Learnings
- Hands-on experience with OpenCV
- Understanding of real-time video processing
- Basics of anomaly detection
- Image processing techniques

## Future Improvements
- Integrate deep learning models for better accuracy
- Add real-time alert notifications (SMS/Email)
- Improve detection for complex scenarios

## Note
Large video files are not uploaded due to size limitations.
